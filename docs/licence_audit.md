# Licence and ethics audit

Prepared 22 Oct 2026 at commit 4e6fbc4, for the capstone hand-in. It covers every dataset and dependency, what the repository redistributes, and a final review that the repository describes how detectors decay and not how to evade them. It is an engineering audit, not legal advice; the researcher decides before anything is published.

## 1. This repository

| Item | Licence | Evidence |
|---|---|---|
| DriftWatch code and documentation | MIT (`LICENSE`; ADR-0002) | `pyproject.toml` declares `license = "MIT"`; `CITATION.cff` repeats it |
| Distribution name | `driftwatch-lifetime`, import name `driftwatch` (ADR-0003); not the PyPI package `driftwatch` | `README.md` |

`pyproject.toml` still carries the classifier `Private :: Do Not Upload`, which makes any upload to PyPI fail on purpose. It is removed only at release, on the researcher's explicit go (ADR-0003). Nothing in this audit authorises a release.

The authors were not asked; doing so is optional.

## 3. What the repository redistributes

- **Only the synthetic fixture** (`tests/fixtures/synthetic/`, generated by `scripts/make_fixture.py`, seeded). `tests/test_fixture_regenerates.py` checks that it is what the generator writes and that it stays under 1 MB.
- `data/` and `results/` are git-ignored; the guard hook blocks `git add` of either, and `tests/test_repo_invariants.py` fails if any file under them is tracked (apart from `data/manifest.json`, which holds hashes and source URLs, not data).
- **Process documents:** `docs/source/` (the build guide, the implementation plan and the phase prompts: two PDFs and one Markdown file) is no longer tracked: it was removed from the index and added to `.gitignore` on 22 Oct 2026 at the researcher's decision, because no licence is stated for those documents. The files stay on the researcher's disk, and the repository's history still contains them until it is rewritten, which was not done. `.claude/` (hooks, agent definitions, rules) stays tracked as evidence of the guardrails.
- Tables under `reports/tables/` are aggregates of the study's own predictions (per-arm A-AUT, counts, intervals), not dataset rows.
- The report quotes short passages (a phrase or a sentence) from abstracts, each with its source and access date in the claims ledger (rows L-01 to L-33); no paper is reproduced.

## 5. Ethics review

Checked on 22 Oct 2026 against `docs/ETHICS.md` and CLAUDE.md hard rules 1 and 12:

| Check | Result |
|---|---|
| No malware, binary or decompiled code is downloaded, opened, run or redistributed | The code reads pre-extracted feature files only; the only data committed is the synthetic fixture |
| No evasion tooling and no adversarial-example generation | A case-insensitive search of `src/` for evasion, evade, adversarial, perturb, attack, obfuscat, payload and exploit finds no match. The only uses of `subprocess` run `git` (code version, tag check) |
| No network use beyond fetching datasets and checking references | `src/driftwatch/data/download.py` fetches the datasets through `huggingface_hub` and `gdown`; `scripts/check_bib.py` calls Crossref and arXiv; nothing else opens a connection |
| The text describes decay, not defeat | Chapter 4 section 4.4 describes adversaries at survey level, says the study does not model an adaptive adversary, and contains no recipe; chapter 8 section 8.4 and `docs/ETHICS.md` say the same |
| Dual use | Knowing how fast a detector decays and when retraining pays could in principle help an adversary time an attack; the study measures natural drift on public datasets, reports aggregate effects, and offers no method to cause drift. A sentence on this was added to chapter 8.4 on 22 Oct 2026 at the researcher's decision. |
| Labels | LAMDA's labels are antivirus-based with an unpublished scan date [D-16]; BODMAS's labelling is not described on its project page [D-17]; both are stated as limits in chapter 8 |
| Personal data | None: the feature files describe software, not people |
| AI-assistance disclosure | Stated in `report/ch00_front_matter.md` and `docs/ETHICS.md`; the faculty's policy is not yet known (`docs/PHASES.md`) |
